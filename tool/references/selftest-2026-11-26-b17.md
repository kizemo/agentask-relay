## 2. 会话命名：`relay-<NN>of<MM>-<阶段短名>`

旧式 `relay-1-<short>` 有两个硬伤：`relay-10` 会排在 `relay-2` 前面；名字里看不出链有多长。

新规则（零填充两位序号 + 链长），例：`relay-01of02`、`relay-10of12`。
激活包里给的是占位式 `relay-01of<MM>-<short stage name>`；真实链第 1 环 `RELAY_LINK=relay-01of02`，
交接行要求子环 `change RELAY_LINK=relay-01of02 to RELAY_LINK=relay-02of02`。

| 文件 | 改了什么 |
|---|---|
| `tool\templates\start-relay.ps1` | `$linkTag` / `$nextLinkTag` / `$nameRule` / `RELAY_LINK` 头 / 两条 `$completionRule` / mcode `title=` 与 tool `task=` 提示 |
| `tool\templates\AGENT-RELAY.md` + `protocol\AGENT-RELAY.md` | 命名规则与交接说明（两份逐字一致） |
| `tool\templates\ACTIVATION-SPAWN-mcode.md` / `ACTIVATION-SPAWN-openclaw.md` | `title` / `task` 示例改零填充 |
| `protocol\relay-prompt.md` | L24 / L51 示例改新式，补零填充说明与 `relay-02of05` 例 |
| `tool\references\deployment-openclaw.md` | L74 `task : relay-01of<MM>-<短阶段名>` |
| `device\start-relay.ps1` | `Copy-Item` 同步；与模板逐字一致由 publish 硬判（漂移 exit 2） |

**没做**：对已存在会话的追溯改名 —— 装置无权改 MCode 会话名，序号从下一条链起生效。

### 命名不是靠断言绿的，是靠生成物自证

`scripts\selftest.ps1` 对会话标题**没有** `relay-<N>-` / `title=` 断言，本批也没有新增断言（改动是纯文本模板，
加断言等于把同一份字符串抄两遍）。证据改为扫自测生成物，且**全部取自 17:34:30 那次运行**（晚于所有改动）：

  完成规则含 `change RELAY_LINK=relay-01of02 to RELAY_LINK=relay-02of02`；
  命名说明含 `relay-10 must not sort beside relay-1`；旧式 `relay-\d+-` 命中 **0**。
- 各 `ACTIVATION-PROMPT.txt`：`title : "relay-01of<MM>-<short stage name>"`；旧式命中 **0**。
