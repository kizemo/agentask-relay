## 3. 这一轮踩的坑（别重试）

1. **改了 selftest 自己会先炸**：把 `($x -split 'a',2)[1] -split 'b',2)[0]` 写进断言，
   PowerShell 直接 `ParserError`，整个门禁起不来（**不是**断言失败，别往测试逻辑里找）。
   拆成两行 `-split` 才过。**改完 selftest 先跑一遍确认能解析。**
2. **断言里的 Windows 路径反斜杠要写两个**：`docs\relay\.relay.lock` 的正则要写
   `docs\\relay\\\.relay\.lock`。少写一个 → 断言假红（工具本身是对的）。
   教训：断言 Windows 路径优先 `[regex]::Escape()` 或直接比字面串。
3. **夹具必须是 git 仓**：安装器对非 git 目录 exit 2。第一版验证脚本没做
   `git init` 就安装，直接 exit 2。
4. **mcode 逐字不变不能靠肉眼**：必须 `git show HEAD:tool/templates/start-relay.ps1`
   渲染同一夹具再逐字节比（本轮用 `MCODE_PROMPT_BYTE_IDENTICAL=True` 钉死）。
