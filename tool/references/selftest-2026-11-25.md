## 实测缺陷与处置

### D1（严重，已修）—— 幂等重跑把目标项目的 `AGENTS.md` 截断成 0 字节

- **症状**：第二次安装 `INSTALL_VERDICT` 未产出，脚本在 `[regex]::Matches` 处抛 `Value cannot be null. (Parameter 'input')`，exit 1；目标 `AGENTS.md` 变成 **0 字节**。
- **根因**：标记块已存在 ⇒ 走「不改动」分支，但该分支**没有给 `$agentsOut` 赋值**；而写盘条件写成 `if ($agentsOut -ne $agentsExisting)` —— `$null -ne "文本"` 为真 ⇒ `WriteAllText(path, $null)` 把文件清零；随后 `Get-Content -Raw` 读到空文件返回 `$null`（不是 `''`）⇒ `Matches($null, …)` 抛异常。
- **修法三条**：① `$agentsOut` 在分支外初始化为原内容；② 写盘条件改用 `$agentsDirty` 布尔标志，**不用内容比较代替**；③ 所有文本读取走 null 安全助手 `Read-TextOrEmpty`。
- **复测**：T2 / T9 / T10 全部通过。

### D2（已修）—— 干跑证据文件曾经是空的

- **症状**：`start-relay.ps1 -DryRun` 的输出没进证据文件（0 B）。
- **根因**：`start-relay.ps1` 用 `Write-Host` 输出，走 **information stream**，`2>&1` 捕不到。
- **修法**：改用 `*>&1` 合并全部流；复测证据 2,666 B，内容有效。

### D3（拷贝轮新发现，已修）—— 安装器 `.ps1` 里直接写了汉字字面量

- **症状**：拷贝轮对目标目录做全库字节扫描时，`tool\scripts\install-relay.ps1` 命中 **18 个非 ASCII 字节**（6 个汉字 × 3 字节），全部集中在第 399 行：`$md.Add('    按 docs\relay\ACTIVATION-PROMPT.txt 启动接力链')`。该文件**无 BOM**，在 PowerShell 7 下读作 UTF-8 侥幸正常，但 Windows PowerShell 5.1 会按 ANSI（GBK）解码 ⇒ 目标仓库 `docs\relay\install-report.md` 里的激活口令变成乱码。
- **为什么早先没抓到**：T4 的 ASCII 判据只覆盖**被装进目标仓库**的两件 `.ps1`（`start-relay.ps1` / `relay-lock.ps1`），**没有覆盖安装器自己**。
- **修法**：字面量改为 ASCII 码点构造，语义不变、文件恢复纯 ASCII：
  ```powershell
  $zhAct = -join [char[]](0x6309)
  $zhChain = -join [char[]](0x542F,0x52A8,0x63A5,0x529B,0x94FE)
  $md.Add('    ' + $zhAct + ' docs\relay\ACTIVATION-PROMPT.txt ' + $zhChain)
  ```
- **复测**：`NON_ASCII=0` / `BOM=False` / `PARSE_ERRORS=0`；对测试仓真实安装 `INSTALL_VERDICT=PASS`（exit 0）；生成报告里的激活口令行非 ASCII 码点恰为 `U+6309 U+542F U+52A8 U+63A5 U+529B U+94FE`（按·启动接力链），与修前意图**逐码点一致**。

## 可复用结论

1. **幂等改写脚本**：输出变量必须在分支外初始化；写盘条件用 dirty 标志；**不要**用「内容比较」代替 dirty 标志。
2. **`Get-Content -Raw` 对空文件返回 `$null`**，任何 `.Contains()` / `[regex]::Matches()` 之前都要兜。
3. **PowerShell 里 `Write-Host` 的内容要 `*>&1` 才能被赋值捕获**，`2>&1` 捕不到。
4. 幂等安装器的自检**必须包含「第二次执行后目标文件 sha16 不变」**这条判据，否则截断类缺陷会潜伏到用户项目里才爆。
5. 收编（adopt）已有家规时，只在目标文件里**加标记**、不改原文本 —— 实测真 PractiLog `AGENTS.md` 哈希未变。
6. **无 BOM 的 `.ps1` 里不能直接写汉字字面量**：UTF-8 字节在 Windows PowerShell 5.1 下会按 ANSI 解码成乱码；用 `-join [char[]](0x…)` 构造。
7. **纯 ASCII 判据必须覆盖工具自身的脚本**，不只是被装进目标仓库的那些文件。
8. 拷贝语料时要**逐件 sha16 对账源与目标**，否则源文件里的老缺陷会被原样搬进新工程面（本轮就是这样才发现 D3）。
