## 1. #3 启动器 `-PlanDoc` 加固（`tool\templates\start-relay.ps1`）

## 2. #4 收编判据加固（`tool\scripts\install-relay.ps1`）

原来只按标题字面匹配（含"接力/relay/自动推进"），现在双判据：

- 判据 a（保留）：标题命中 → `reason=title`；
- 判据 b（新增）：按 `^##\s` 切节做**内容指纹**打分，十条信号 `relay.json / relay-lock / start-relay /
  session_create / in_progress / max_stages / next_session / awaiting_user / 接力 / relay`，
  单节命中 ≥4 条即合格：
  - 恰好一节合格 → 包裹收编（保留原文 + `BEGIN/END RELAY-PORT`），`reason=content_signature`；
  - ≥2 节合格 → 不猜 → `WARN agents_relay_section_ambiguous matches=N` + 追加托管块 + `review=keep_a_single_relay_section`；
  - 无合格节 → 直接追加托管块（与旧行为一致）。

实测（用例 2-4）：


`count=8` 那节是**不含任何标题关键词**的接力家规（标题写成 `## How work advances here`），旧判据会漏 → 新判据抓住；

## 5. 工具坑实录（run1 的 5 条 FAIL，都是脚手架写错）

1. **成功判据字样**是 `INSTALL_VERDICT=PASS`（`install-relay.ps1:458`），我断言成 `INSTALL_VERDICT=OK` → 假失败。
2. **安装器干跑不打印 stdout**：`-DryRun` 只写 `docs\relay\install-dryrun.txt`（`install-relay.ps1:401-407`），
   所以「安装器把 `-PlanDoc` 透传给干跑」必须读该文件，不能抓 stdout。
3. **`relay-lock.ps1` 参数不是 `-RepoRoot -Owner`**：真实参数是 `-Action -SessionId -Title -Stage -TtlSeconds -LockPath`；
   传错被参数绑定拒绝，且 `2>&1 | Select-Object` 吞掉退出码 → 必须按真实参数拼。
4. **不要用目录名子串匹配判歧义**：临时仓库名叫 `repo-ambiguous`，任何 `ambiguous` 断言都会假通过；
   改成锚定 WARN 码 `agents_relay_section_ambiguous`。
5. **`Get-Content -Raw` 读空文件得 `$null`**，`Select-String -InputObject $null` 直接报错；
   用 `Read-TextOrEmpty`（`[IO.File]::ReadAllText` + 空串兜底）。

另有两条已在旧留证中记录、本轮继续复用：`Write-Host` 证据需 `*>&1` 捕获；PowerShell 里 `.Count` 对字符串要先包 `@()`。
